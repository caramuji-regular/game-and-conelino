# Coninho — Fase 1-1

Protótipo de plataforma 2D para abrir diretamente no navegador.

## Ações adicionadas da nova folha de sprites
- IDLE — 2 frames
- RUN — 6 frames
- JUMP — 2 frames
- PULO — 6 frames
- ACENANDO — 4 frames
- AGACHANDO — 4 frames
- TOMANDO DANO — 3 frames
- ESQUERDA — 3 frames
- DIREITA — 3 frames

## Controles
- ← / → ou A / D: mover
- Espaço / Z: pular e pulo duplo
- X: acenar
- ↓ / S: agachar
- R: reiniciar
- Celular: botões na tela

As animações são desenhadas no Canvas com um loop de animação do navegador.
